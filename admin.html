จัดการสินค้า

มีการแก้ไขที่ยังไม่ได้บันทึก ดูหน้าร้าน
1เพิ่ม แก้ ซ่อน หรือลบสินค้า อัปรูป ใส่ราคา
2กด บันทึกขึ้นเว็บ ระบบส่งข้อมูลและรูปขึ้น GitHub ให้เอง
3รอ 1–2 นาที หน้าร้านจะอัปเดตเอง
กำลังโหลด…
วิธีเชื่อมต่อ GitHub (ทำครั้งเดียวต่อเครื่อง) และวิธีอัปโหลดแบบเดิม
  1. เปิด github.com/settings/personal-access-tokens/new (ต้องล็อกอิน GitHub อยู่)
  2. Token name: chana-admin · Expiration: เลือกนานที่สุดที่มีให้
  3. Repository access: เลือก Only select repositories แล้วเลือก chana-velvetbloom.github.io
  4. Permissions → Repository permissions → Contents: เลือก Read and write
  5. กด Generate token แล้วคัดลอกรหัสที่ขึ้นต้นด้วย github_pat_ มาวางในปุ่ม ⚙ เชื่อมต่อ ด้านบน

รหัสนี้เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ลูกค้าที่เปิดหน้าร้านมองไม่เห็น ถ้าใช้คอมเครื่องอื่นหรือมือถือ ต้องวางรหัสอีกครั้ง และห้ามส่งรหัสนี้ให้ใคร

แบบเดิม (สำรอง):

  1. เปิด repository ของเว็บใน github.com แล้วกด Add file → Upload files
  2. ลากโฟลเดอร์ data และ images ที่แตกจาก zip มาวาง ไฟล์เดิมชื่อเดียวกันจะถูกแทนที่
  3. กด Commit changes รอประมาณ 1–2 นาที หน้าเว็บจะอัปเดตเอง

รูปที่อัปผ่านหน้านี้จะถูกย่อเป็น JPG กว้างไม่เกิน 1200px และตั้งชื่อตามรหัสสินค้าให้อัตโนมัติ (เช่น CH-106-1.jpg) ส่วนไฟล์ CSV เปิดแก้ใน Excel ได้ แล้วกด “นำเข้า CSV” กลับมา
