C.HANA Velvet Bloom – เว็บแคตตาล็อก
====================================

ไฟล์ในโฟลเดอร์นี้
  index.html        หน้าร้านสำหรับลูกค้า
  admin.html        หน้าจัดการสินค้า (เพิ่ม/แก้/ซ่อน/ลบ อัปรูป ใส่ราคา)
  data/products.csv ข้อมูลสินค้าทั้งหมด (เปิดใน Excel ได้)
  images/           รูปสินค้า ตั้งชื่อตามรหัส เช่น CH-001-1.jpg
  assets/           โลโก้ QR LINE ฟอนต์ และสคริปต์
  ตั้งค่า LINE ID อยู่ในไฟล์ assets/common.js บรรทัดบนสุด

ขึ้นเว็บครั้งแรก (GitHub Pages ฟรี)
  1. สมัคร github.com แล้วกด New repository ตั้งชื่อ เช่น chana-catalog เลือก Public
  2. กด "uploading an existing file" ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ไปวาง แล้วกด Commit changes
  3. ไปที่ Settings > Pages > Branch เลือก main / (root) แล้วกด Save
  4. รอ 1–2 นาที จะได้ลิงก์ https://<ชื่อผู้ใช้>.github.io/chana-catalog/
     หน้าเว็บจะสร้าง QR Code ของลิงก์นี้ให้เองที่ส่วน "แชร์แคตตาล็อก"

อัปเดตสินค้า
  1. เปิด https://<ลิงก์เว็บ>/admin.html
  2. เพิ่มหรือแก้สินค้า อัปรูป ใส่ราคา แล้วกด "บันทึกเป็นไฟล์" จะได้ catalog-update.zip
  3. แตก zip แล้วใน GitHub กด Add file > Upload files ลากโฟลเดอร์ data และ images ไปวาง แล้วกด Commit changes

สร้าง eBook PDF
  1. ในหน้า admin.html กด "สร้าง eBook PDF" (ใช้ข้อมูลล่าสุดในหน้านั้น รวมที่ยังไม่ได้บันทึก)
     หรือเปิด ebook.html เพื่อสร้างจากข้อมูลที่ขึ้นเว็บแล้ว
  2. เลือก "ทั้งร้าน" หรือเลือกหมวด แล้วกด "บันทึกเป็น PDF"
  3. ในหน้าต่างพิมพ์ เลือกปลายทาง "Save as PDF / บันทึกเป็น PDF"
     ติ๊ก "Background graphics / กราฟิกพื้นหลัง" และตั้ง Margins = None ถ้ามีตัวเลือก
     (บนไอโฟน: ปุ่มแชร์ > พิมพ์ > ถ่างนิ้วที่ตัวอย่าง > แชร์ > บันทึกไปยังไฟล์)

หมายเหตุ
  - ช่องราคาเว้นว่างไว้ หน้าเว็บจะขึ้นว่า "สอบถามราคาทาง LINE"
  - รูป .HEIC จากไอโฟนบางเบราว์เซอร์อ่านไม่ได้ ให้ส่งออกเป็น JPG ก่อน
    (ตั้งค่าไอโฟน > กล้อง > รูปแบบ > เลือก "เข้ากันได้มากที่สุด")
  - หน้า admin.html ไม่ได้แก้ข้อมูลบนเว็บโดยตรง มันแค่สร้างไฟล์ให้ จึงไม่ต้องตั้งรหัสผ่าน
